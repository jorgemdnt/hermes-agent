# Conversation

## Sub-features

Assistant/user bubbles and loading, grouped notices, floating bot pill and jump-to-latest, text composer and slash/mention suggestions, file/photo previews and removal, message actions.

## How to get to it (user POV)

Choose Frodo's long conversation in Chats. Scroll its transcript under the floating identity pill. Type in Message; use + to attach a file or photo, but do not send from this fixture without an explicitly configured fake provider. The three-dot message controls expose actions. Press ⌘/ for shortcut help. On desktop press Ctrl+1 / Ctrl+2 to switch Bots / Chats; Cmd+1–9 opens list items rather than switching tabs.

For a new conversation, click the plus in the sidebar or a project group's plus. The draft hero should say “What should we build in Orion?” with Orion as an inline picker. The composer is centered beneath it; the project and Current checkout / New worktree selectors live as compact controls immediately below the composer, not in a separate setup form. Choose New worktree: the branch defaults to a slug of the first message. Enter `../../bad` and assert the branch validation error and disabled send. Correct it and assert send is enabled. For real sending, configure only the disposable fixture home with a local fake provider. Capture Creating worktree → Starting chat → Bot is working → actual reply, then force the workspace request to fail once and assert Retry retains the draft. Never run these sends against a real Hermes home.

## Gotchas

The fixture intentionally lacks a model gateway unless you explicitly configure a disposable local fake provider. `fixture.md` is read-only preview input; attachment selection does not prove upload. An alternating long transcript ends with an assistant message to avoid the app's real interrupted-turn notice; two process notices are placed near its end so they can be clicked without a floating-control overlap. A one-off CDP screenshot viewport does not persist to the next command; repeat `--width 390` for phone actions and take screenshots at both sizes.
